## Changes to existing tests

The fixes deliberately changed behaviour that some existing tests had
encoded:

* `tests/test_security_hardening.py`: three raw-socket tests sent
  `Host: x`, which the Host allowlist now refuses. They test unrelated
  limits, so they now send `Host: 127.0.0.1`.
* `tests/test_server.py::TestBindGuard`: a non-loopback bind with the
  flag now also needs a token. The test was renamed
  `test_allows_non_loopback_with_explicit_flag_and_a_token`.
* `tests/test_core.py::TestAnswerQuestions::test_noul_answer_shape` and
  the core selftest: fast answers carry the four degradation fields.
* `tests/test_deliberate.py`: `test_all_malformed_falls_back_to_half`
  became `test_all_malformed_is_degraded_not_a_plausible_half`.
